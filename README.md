# Pandas Data Analysis Projects

This repository contains Python programs and projects using the Pandas library for data analysis, data cleaning, and data manipulation.

## 📌 Features
- Data loading (CSV, Excel, etc.)
- Data cleaning (handling missing values, duplicates)
- Data manipulation (filtering, grouping, sorting)
- Exploratory Data Analysis (EDA)
- Aggregation and statistics
- Time series analysis

## 🛠 Technologies Used
- Python
- Pandas
- NumPy (optional)
- Matplotlib / Seaborn (for visualization)

## 📂 Project Structure
- Data Cleaning
- Data Manipulation
- EDA (Exploratory Data Analysis)
- Real-world datasets
- Practice programs

## 🎯 Purpose
This project is designed to practice data analysis skills and understand how to work with structured datasets using Pandas.
